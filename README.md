# もちもち16タイプ リール自動投稿

Instagram「もちもち16タイプ（@mochi16type）」のリールを、毎日21時ごろに1本ずつ自動で公開するための置き場です。

## 中身

| 場所 | 役割 |
|---|---|
| `videos/` | 公開する動画（mp4） |
| `queue.json` | いつ、どの動画を、どの投稿文で出すかの予定表 |
| `posted.json` | 公開済みの記録（自動で追記されます） |
| `scripts/post_reel.py` | その日の動画を1本公開するプログラム |
| `scripts/check_token.py` | トークンの期限や権限を確かめるプログラム（投稿はしません） |
| `.github/workflows/post.yml` | 毎日 20:50（日本時間）に投稿を動かす設定 |
| `.github/workflows/check.yml` | 毎週月曜にトークンの期限を確かめる設定 |

## お知らせが届くとき

次のようなときは、このリポジトリの「Issues」に自動でお知らせが立ち、登録しているメールに通知が届きます。

- 投稿に失敗したとき
- 予定に入っている動画が残り7日分を切ったとき
- トークンの期限まで14日を切ったとき

## 守っていること

- トークンは GitHub の Secrets（`IG_ACCESS_TOKEN`）にだけ保存し、ログにも出しません
- 同じ日に二重投稿しないよう、公開済みの日付は `posted.json` で管理しています
- このアカウントは16タイプ性格論をもとにしたファンメイドの作品です。公式の診断・団体とは関係ありません
